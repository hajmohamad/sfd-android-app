# سامانه بررسی خودکار غذاهای کالینان دانشگاه اصفهان (sfd.ui.ac.ir)

این اسکریپت به صورت کاملاً خودکار وارد سامانه تغذیه کالینان شده و امکانات زیر را ارائه می‌دهد:

1. **نمایش موجودی کاربر:** استخراج دقیق موجودی اعتبار سلف و اعتبار رستوران‌های آزاد.
2. **سلف‌های پیش‌فرض ناهار و شام:** انتخاب سلف‌های دیفالت در اولین اجرا و ذخیره در `config.json` (عدم پرسش مجدد در دفعات بعد).
3. **بررسی ظرفیت غذاهای رستوران‌های آزاد (یاس ۱ و یاس ۲):** مشاهده دقیق ظرفیت باقیمانده هر غذا (به تفکیک پرس‌های مانده) برای رستوران دیفالت، یا مقایسه همزمان تمام رستوران‌ها.
4. **ورود ۱۰۰٪ خودکار با OCR:** تشخیص خودکار کپچا بدون نیاز به تایپ کاربر.

---

## 🚀 دستورات اجرا

### ۱. اجرای عادی (موجودی + برنامه سلف + ظرفیت رستوران دیفالت)
```bash
python3 check_food.py
```

### ۲. مشاهده و مقایسه ظرفیت تمام رستوران‌های آزاد (یاس ۱ و یاس ۲)
```bash
python3 check_food.py --all-restaurants
```

### ۳. مشاهده ظرفیت یک رستوران خاص
```bash
# بر اساس نام یا شماره رستوران
python3 check_food.py --restaurant "یاس دو"
```

### ۴. تغییر سلف یا رستوران پیش‌فرض
```bash
python3 check_food.py --change-defaults
```

### ۵. خروجی در قالب JSON
```bash
python3 check_food.py --json
```
