# اتوماسیون هوشمند سامانه تغذیه کالینان دانشگاه اصفهان (sfd.ui.ac.ir)

این اسکریپت پایتون فرآیندهای ورود خودکار، بررسی موجودی، استعلام ظرفیت سلف و رستوران‌ها، **اولویت‌بندی غذاها**، **رزرو خودکار بر اساس سلیقه کاربر** و **مدیریت هوشمند کسری موجودی و هدایت به درگاه پرداخت** را انجام می‌دهد.

---

## 🌟 ویژگی‌های کلیدی

1. **لاگین ۱۰۰٪ خودکار با OCR داخلی:** حل کپچاهای ۴ رقمی بدون نیاز به ورود دستی یا ابزار خارجی.
2. **استخراج دقیق موجودی:** تفکیک اعتبار سلف عادی و اعتبار رستوران‌های آزاد (کافه‌تریا).
3. **اولویت‌بندی و تطبیق هوشمند (Fuzzy Matching):**
   - تعیین اولویت ۱ تا N غذاها به تفکیک ناهار و شام در `config.json`.
   - انطباق هوشمند زیررشته و کلمات کلیدی غذاها با نام‌های واقعی منو (مثلاً انطباق «قورمه» با «چلو خورشت قورمه سبزی»).
   - تعریف لیست سیاه (`blacklist`) جهت جلوگیری از رزرو غذاهای نامطلوب.
   - امکان عدم رزرو در صورت نبود گزینه‌های اولویت‌دار (`skip_if_no_preference_match`).
4. **رزرو خودکار (Auto-Reservation):**
   - بررسی روزانه و وعده‌ای ظرفیت غذاها (`capacity > 0`).
   - مرتب‌سازی بر اساس بالاترین اولویت کاربر و انتخاب بهترین غذای موجود.
   - جلوگیری از رزرو تکراری در صورتی که کاربر قبلاً برای آن وعده غذا رزرو کرده باشد (با امکان دور زدن توسط `--force-reorder`).
5. **مدیریت هوشمند کسری موجودی و تونل احراز هویت اختصاصی مرورگر:**
   - بررسی موجودی قبل از اقدام به رزرو (سلف یا رستوران).
   - محاسبه دقیق مابه‌التفاوت و پیشنهاد مبلغ گردشده شارژ بر اساس `round_topup_to_nearest`.
   - **حل ریشه‌ای مشکل نبود توکن در کروم (Authenticated Browser Tunnel):** اسکریپت یک تونل پروکسی محلی موقت ایجاد می‌کند که کوکی‌ها و نشست فعال لاگین پایتون را مستقیماً به مرورگر منتقل می‌کند. مبلغ پیشنهادی نیز به‌صورت خودکار در فیلد مبلغ درج شده و کاربر بدون نیاز به لاگین مجدد، مستقیماً روی درگاه شاپرک کلیک کرده و پرداخت می‌کند.
   - حالت استعلام و انتظار (`Wait/Poll`): کاربر پرداخت را در درگاه شتاب انجام داده و با فشردن کلید Enter یا استعلام خودکار هر ۵ ثانیه، به محض تایید افزایش موجودی، پروکسی بسته شده و فرآیند رزرو نهایی می‌شود.
6. **رزرو هوشمند سلف عادی و جابجایی خودکار به هفته بعد:**
   - تشخیص وضعیت روزهای هفته و سوئیچ خودکار به هفته بعد (`هفته بعدی`) در سامانه سلف.
   - انطباق گزینه‌های غذایی هر روز با لیست اولویت‌های کاربر و فشردن دکمه «ذخیره» مربوطه.
7. **حالت شبیه‌سازی (`--dry-run`):** امکان اجرای آزمایشی تصمیم‌گیری و ارزیابی موجودی بدون ارسال درخواست نهایی رزرو.
8. **ویزارد تعاملی در ترمینال (`--set-preferences`):** مدیریت و ویرایش آسان اولویت‌ها بدون نیاز به ادیت دستی فایل JSON.

## 🚀 دستورات اجرا

### ۱. اجرای عادی (بررسی موجودی + برنامه هفتگی + ظرفیت رستوران)
```bash
python3 check_food.py
```

### ۲. رزرو خودکار غذا بر اساس اولویت‌ها
```bash
# رزرو خودکار هر دو بخش (سلف عادی هفته بعد + رستوران‌های آزاد)
python3 check_food.py --auto-reserve

# رزرو خودکار فقط برای سلف عادی (هفته بعد)
python3 check_food.py --auto-reserve --target self

# رزرو خودکار فقط برای رستوران‌های آزاد (یاس ۱ و ۲)
python3 check_food.py --auto-reserve --target cafeteria

# رزرو خودکار برای یک وعده مشخص (ناهار یا شام یا صبحانه)
python3 check_food.py --auto-reserve --meal lunch
python3 check_food.py --auto-reserve --meal dinner

# شبیه‌سازی کامل مراحل تصمیم‌گیری، بررسی هفته بعد و محاسبه کسری بدون رزرو نهایی
python3 check_food.py --auto-reserve --dry-run

# تغییر و جایگزینی رزروهای قبلی در صورت وجود
python3 check_food.py --auto-reserve --force-reorder
```

### ۳. مدیریت و ویرایش اولویت‌های غذایی (ویزارد تعاملی)
```bash
python3 check_food.py --set-preferences
```

### ۴. مشاهده و مقایسه ظرفیت تمام رستوران‌های آزاد (یاس ۱ و یاس ۲)
```bash
python3 check_food.py --all-restaurants
```

### ۵. تغییر سلف‌ها یا رستوران پیش‌فرض
```bash
python3 check_food.py --change-defaults
```

### ۶. افزایش دستی اعتبار حساب (سلف عادی یا رستوران آزاد)
```bash
# افزایش دستی اعتبار سلف با مبلغ دلخواه (مثال: ۱,۰۰۰,۰۰۰ ریال)
python3 check_food.py --topup 1000000

# افزایش دستی اعتبار رستوران آزاد
python3 check_food.py --topup 500000 --topup-type restaurant

# اجرای تعاملی (اسکریپت مبلغ را از شما در ترمینال می‌پرسد)
python3 check_food.py --topup
```

### ۷. دریافت خروجی ساختاریافته JSON
```bash
python3 check_food.py --json
```

## 🛡️ گردش کار پرداخت و رزرو (Payment & Reservation Flows)

سامانه تغذیه کالینان دارای دو فرآیند کاملاً مجزا برای سلف و رستوران آزاد است که این اسکریپت هر دو را به صورت هوشمند مدیریت می‌کند:

### ۱. رزرو سلف‌های عادی دانشگاه (`Reservation.aspx`):
1. اسکریپت به صورت خودکار به تقویم **هفته بعد** منتقل می‌شود تا روزهای مجاز را رزرو نماید.
2. بهترین غذاها طبق اولویت‌بندی شما انتخاب می‌شوند.
3. در صورت کسری موجودی سلف، اسکریپت مبلغ کسری و شارژ پیشنهادی را محاسبه می‌کند.
4. **پل احراز هویت محلی (`AuthenticatedPaymentBridge`)** فعال شده و صفحه افزایش اعتبار را مستقیماً همراه با کوکی‌ها و توکن نشست فعال شما در مرورگر کروم باز می‌کند (بدون نیاز به لاگین مجدد).
5. پس از پرداخت شما در شاپرک، اسکریپت افزایش موجودی را استعلام کرده و دکمه ذخیره سلف را می‌زند.

### ۲. رزرو رستوران‌های آزاد یاس ۱ و ۲ (`CafeteriaReservation.aspx`):
1. نیازی به افزایش اعتبار سلف از قبل **نیست**.
2. اسکریپت تیک غذای برتر دارای ظرفیت را فعال کرده، تعداد را روی **۱** قرار می‌دهد و دکمه **ذخیره** را ارسال می‌کند.
3. سامانه کالینان سفارش موقت ایجاد کرده و شناسه `CreditId` تولید می‌کند.
4. صفحه **پیش‌پرداخت رستوران** (`CafeteriaReservation_SelectBank.aspx`) با نشست احراز هویت شده در مرورگر شما باز می‌شود.
5. طبق مقررات سامانه کالینان، شما **۳ دقیقه** مهلت دارید روی درگاه بانک (شاپرک) کلیک کرده و هزینه سفارش را پرداخت نمایید.
6. اسکریپت به صورت همزمان وضعیت را مانیتور کرده و پس از پرداخت موفق، تاییدیه قطعی رزرو را صادر می‌کند.
